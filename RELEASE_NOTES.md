Fixes how the recorder's recording format is shown. A recorder set to 16-bit PCM now shows "PCM 16 bit" instead of just "16".

Also the first version published through the automatic Releases page. Earlier changes in this module: the transport state (Playing, Recording, Stopped and so on) is now a variable and button feedback, every recorder status value has a variable, and new actions were added for media selection, record input, record monitor and recording format.

To install: download the file ending in .tgz below, then in Companion open Modules and import the module package.
